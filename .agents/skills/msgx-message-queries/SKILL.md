# 消息检索与存储

适用：1.0.3；约定更新：2026-11-03。

- Store持有写连接与迁移；耗时后台查询在线程内创建并关闭自己的只读连接，正常 `mode=ro` 读取WAL。禁止共享接收连接或用 `immutable=1` 忽略运行中的WAL。
- 过滤与关键词须在 LIMIT 前生效；历史逐图OCR/语义从 `message_images` 检索，不只依赖父消息聚合文本。查询和展示不触发语义API。
- 活跃度统计北京时间自然日内未过滤消息，以 `messages` 为计数单位；多图及多接收凭据的JOIN不能重复计数。群筛选和屏幕条数不改变统计口径。
- 活跃度范围为当前账号最新群成员快照与已配置统计群的交集；成功空群列表有效，查询失败保留旧快照。按今日、近3/7/30天日均的10%/20%/30%/40%加权；7/14/30天曲线只查选中群，补零不代表缺失期间真实无消息。
- 普通群同步隐藏已退群但保留历史；明确退群及消息删除属于 `msgx-group-operations`。关键词定位用同群时间/主键索引前后各限40条，复用多图/本人关系读取，过滤在截取前生效。
- 账号、@对象和同群引用用于本人关联；排除@全体成员，不能靠昵称或正文猜测。没有原始引用的历史关系不凭空补全。
- 修改迁移/SQL或排查上游本人消息时，读取 [连接归属、705迁移与查询证据](references/storage.md) 对应章节；以同规模数据和实际查询计划验证性能，不用少量合成行替代大库证据。

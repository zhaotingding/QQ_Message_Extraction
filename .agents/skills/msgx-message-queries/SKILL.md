# 消息检索与存储

负责消息读取、统计口径与存储迁移。首屏和组合筛选按 2026-11-23 开发分支核对，历史性能数据各自标明测量范围。

- 先区分查询正确性、统计口径、性能或迁移；从当前调用方进入 `message_store.py` 等 Store 模块，Electron 展示问题先定位 `desktop/messages_api.py`，不在页面重算另一套统计。只读查询不能顺带创建空库、执行迁移或回填。

- Store 持有写连接与迁移。列表和本人关联视图在自己的只读连接上用一个事务取消息、逐图信息及群选项。月榜按视图加载。涉及首屏延迟或筛选范围时先读[列表首屏与组合筛选](references/storage.md#列表首屏与组合筛选)。活动数据库使用 `mode=ro` 读取已提交的 WAL。
- 过滤与关键词须在 LIMIT 前生效；历史逐图OCR/语义从 `message_images` 检索，不只依赖父消息聚合文本。查询和展示不触发语义API。
- 活跃度统计北京时间自然日内未过滤消息，以 `messages` 为计数单位；多图及多接收凭据的JOIN不能重复计数。群筛选和屏幕条数不改变统计口径。
- 活跃度范围为当前账号最新群成员快照与已配置统计群的交集；成功空群列表有效，查询失败保留旧快照。按今日、近3/7/30天日均的10%/20%/30%/40%加权；7/14/30天曲线只查选中群，补零不代表缺失期间真实无消息。
- 普通群同步隐藏已退群但保留历史；明确退群及消息删除属于 `msgx-group-operations`。关键词定位用同群时间/主键索引前后各限40条，复用多图/本人关系读取，过滤在截取前生效。
- 账号、@对象和同群引用用于本人关联；排除@全体成员，不能靠昵称或正文猜测。没有原始引用的历史关系不凭空补全。
- 修改 SQL 前核对调用方的时间区间：底层历史接口与外层自然日报可能采用不同开闭边界，不能重复换算或漏掉零点。字段迁移先按现行 Store 版本和 WAL 一致性备份验证，不因旧文档写 705 就重放迁移。
- 读取 [连接归属、迁移与查询证据](references/storage.md)对应章节后，用当前数据规模和实际查询计划验证受影响行为；旧合成测量不是生产性能承诺，小样本也不能替代大库证据。上游本人消息缺失先核对实际 adapter 配置，不能仅据本地支持推定上游已发送。

# 图片初筛与分析

适用：1.0.0；约定更新：2026-10-31。

- 复用现有 OCR 与有界上下文的规则初筛，不把它称为本地视觉模型或宣称已知准确率；表情包不下载/OCR/上传。单个后台队列不阻塞消息接收与下载。
- 图片使用独立已保存 API 配置，缺省跟随摘要；快照冻结密钥归属、模型和费率。新任务尊重该配置的较低输出上限，不能复用摘要密钥或无声回退到另一个服务。
- 自动上传须显式启用；候选受当前账号成员快照、统计群、分数、材料日期、每日次数和估算预算约束。次数与未知状态持久化；请求前先 claim，关闭或中断后不盲目重发。
- 图片语义成功落库后才自动纳入摘要；摘要只用已保存材料，不在阅读或生成时补调用图片 API。缓存命中、写入和同图语义复用是不同事实。
- 改筛选、候选或计费控制前，读取 [调用边界与验证](references/screening.md)；用合成图片、临时库和模型替身验证，真实发送图片需当前任务的具体授权。

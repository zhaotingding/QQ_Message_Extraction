# 摘要恢复与费用

适用：0.9.9；整理日期：2026-10-15。

- 当前生成入口为 `Summarizer.run_period`；北京自然周期左闭右开，报告按内容窗口排序，生成时间只作元数据。旧手动摘要HTTP入口继续拒绝，不能为恢复故障复活旧生成路径。
- 优先复用成稿、已完成分块和后台响应。有response_id且结果仍未明时取回原任务，沿用材料及原API/费率快照；无ID且提交结果未知时保持blocked，重新提交需要具体授权。已确认失败的补生成依现有调度分支处理。
- 用量账本与 `accounted` 同事务提交；成稿保存失败继续本地恢复，不能再次生成或重复记账。补生成核对任务最新修订并唤醒原调度，不另起并行循环。
- 官方OpenAI的Flex费率输入以Standard单价为基准，按响应实际档位估算；未返回时标明请求档位推算，未知用量不算免费。余额覆盖日期与北京时间账本一致。
- 排查失败、修改请求/调度/费用时读取 [恢复链路和计费证据](references/recovery.md)，区分已提交、可取回、确定失败及结果未知，再决定后续动作。历史经验不是发送聊天或增加费用的授权。

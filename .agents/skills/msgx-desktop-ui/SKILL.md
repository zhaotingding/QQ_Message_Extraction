# 桌面交互与进程归属

适用：0.9.9；整理日期：2026-10-15。

- Tk控件只在主线程操作；后台传普通数据和任务身份，旧进程、旧筛选、旧文章或序号的结果不能覆盖当前页面。
- `ServiceProcess` 独占Popen与恢复状态，`ui/service.py` 持有Tk定时器。回收只针对持有的进程树及明确目标协议安装目录，不按Python/QQ名称全部结束。
- 保留异常退出5/15/30秒最多三次、稳定300秒重置；手动停止、关闭、预期清理及退出码0/2不自动拉起。自动恢复只用已保存配置。
- 扫码结束须收到目标账号在本轮操作后的新群消息，连接、心跳、群列表和历史计数不能替代。二维码换代及展示失败重试的细节见参考资料。
- 阅读保存待完成不等于成功；成功回调后才切换文章或关闭，失败保留草稿。批注坐标属于Tk渲染文字，不是Markdown原文切片；HTML缺失时读数据库正文，不调用模型补读。
- 涉及上述交互时读取 [扫码、恢复与批注的已验证流程](references/desktop.md) 相应章节，按实际操作结果显示忙碌、成功、失败或取消。

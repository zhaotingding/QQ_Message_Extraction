# 隔离回归与测试整理

适用：msgx 0.9.9 的现有测试布局；整理日期：2026-10-15。保留旧目录名称以兼容现有文档链接，本技能只负责测试域。

## 执行要点

- 以 `tests/run_all.py` 为套件入口。先运行能暴露本次改动风险的相关组；跨模块整合再运行必要完整回归，不因技能加载重跑全部测试。
- GUI 测试在导入应用前隔离 `MSGX_ROOT`、`MSGX_PREFS`。只更换数据库路径仍可能写真实日志、VBS 或读取图标；替换真实凭据与网络边界。
- 服务验收使用临时库、随机端口、测试协议目录并禁用模型和真实 QQ 恢复，清除外层偏好及 API 密钥环境。结束时等待所属进程、关闭管道和 Tk 回调，再回收临时目录。
- 删除测试前对照当前调用链，区分废弃场景、重复检查和独有行为；共享引擎的完整材料、恢复、费用或状态检查迁到现用入口后才能删旧脚本。
- 断言实际行为。检查结果不得因字典键相同被覆盖；进程已经退出不等于连接建立，保存被受理不等于落盘成功。
- 模拟接口、实际 Tk、本机 HTTP、真实平台验收分别报告。原生凭据实写测试的显式开关保持，不把跳过标为通过。

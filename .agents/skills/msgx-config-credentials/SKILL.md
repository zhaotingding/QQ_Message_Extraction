# 配置与凭据

适用：0.9.9；约定更新：2026-10-20。运行验证日期与范围见参考资料。

- 主配置按显式路径、`.ui/config.local.yaml`、共享 `config.yaml` 的顺序选择，本机主配置完整替代共享文件；随后仍叠加 `.ui/preferences.yaml`。统一复用 `config.load()` 与 `yaml_config.py`，GUI 仅保存偏好，不改共享或本机主配置；外部协议和 Python 打包格式沿工具标准保留。
- 区分已保存配置、编辑框草稿和在途任务快照。新任务用已保存选择；在途材料、模型和费率不随页面切换改变。
- 密钥由 Windows 凭据管理器保存，按配置标识和完整 API 基础地址隔离；不能仅按服务商或主机名复用。保留既有 OpenAI 凭据标识。
- 新克隆不等于新凭据：同一 Windows 用户可能读取已有密钥。恢复数据库前核对库内图片／报告绝对路径，不能把拷贝数据库后的目录当作隔离副本；恢复边界见参考资料。
- 凭据写入与偏好落盘是两步，准确显示全部成功、部分成功和失败；失败保留用户输入。导出不包含密钥，导入拒绝携带密钥的配置。
- 变更配置或旧格式迁移时，按需读取 [优先级、迁移及证据](references/configuration.md)，核对字段值、类型和保存行为；凭据实写须按已有具体授权执行。

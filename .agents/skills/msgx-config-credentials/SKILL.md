# 配置与凭据

适用源码版与安装版的共享配置/凭据机制。2026-11-16 静态核对 `config.py`、`prefs.py` 与 Electron 设置入口；历史运行证据见参考。

- 先辨源码/安装模式及有效资料根，再用 `config.config_path()` 定位实际主配置，不根据当前 shell 目录猜测。源码默认依次选显式路径、资料根 `.ui/config.local.yaml`、共享 `config.yaml`；安装版还须核对 `PROGRAM_ROOT` 与资料根的分离，细节见参考。本机主配置完整替代共享文件，随后仅按实际 `MSGX_PREFS` 叠加偏好，不能假定直接 CLI 自动继承窗口偏好。
- 复用 `config.load()`、`yaml_config.py`、`prefs.update()`；Electron 设置从 `desktop/settings_api.py` 进入，旧 Tk 从 `ui/settings.py` 进入，均不另写配置系统或改共享主配置。外部协议和 Python 打包格式沿工具标准保留。
- 区分已保存配置、编辑框草稿和在途任务快照。新任务用已保存选择；在途材料、模型和费率不随页面切换改变。
- 摘要与图片可独立选择已保存 API profile；图片空选择跟随摘要。保存界面未展示的本机参数时保留原值，不用默认值覆盖隐藏配置。
- 图片参数、规则和外观可分别局部保存；读取最新YAML再合并，保留其他模块、隐藏字段和显式空列表。已保存个人值优先，源码升级不重置为新用户初值。
- 密钥由 Windows 凭据管理器保存，按配置标识和完整 API 基础地址隔离；不能仅按服务商或主机名复用。保留既有 OpenAI 凭据标识。
- 新克隆不等于新凭据：同一 Windows 用户可能读取已有密钥。恢复数据库前核对库内图片／报告绝对路径，不能把拷贝数据库后的目录当作隔离副本；恢复边界见参考资料。
- API参数与密钥使用独立保存动作；切换不提交其他模块草稿，新建复制当前参数并立即持久化。显示实际配置文件、用途和系统凭据目标，失败保留输入；导出不含密钥，导入拒绝携带密钥。
- 修改前区分配置选择、参数保存、密钥保存与资料迁移。按需读 [优先级、迁移及证据](references/configuration.md)对应章节；新供应商能力或协议改动可结合可用的个人 llm-api-integration，项目路径与凭据身份仍以这里为准。
- 用临时 YAML 和凭据替身核对局部保存、失败留稿与重开读回；涉及新旧界面时分别验证受影响入口。真实凭据实写、恢复生产资料及可能发起费用的首次服务启动仍按已有具体授权执行。
